# SQL Queries

This project contains SQL queries based on a **Food Delivery Management System**.

## Files

* **Filtering_Queries.sql** – Basic SELECT, WHERE, ORDER BY, LIMIT, LIKE, IN, NULL, and filtering queries.
* **Aggregate_Queries.sql** – Aggregate functions such as COUNT, SUM, AVG, MIN, MAX, GROUP BY, and HAVING.
* **JOIN_Queries.sql** – INNER JOIN, LEFT JOIN, RIGHT JOIN, and queries combining multiple tables.
* **Date_Functions_Queries.sql** – Date and time functions such as YEAR, MONTH, DAY, DATE_ADD, DATE_SUB, DATEDIFF, and DATE_FORMAT.
* **Advanced_Queries.sql** – Advanced business-related queries using multiple tables, aggregations, and calculations.

## Main Tables

The queries use tables such as:

* Customers
* Restaurants
* Orders
* MenuItems
* MenuCategories
* Payments
* Reviews
* Delivery
* DeliveryPartners

## Purpose

These queries are created for **SQL practice and data analysis**. They demonstrate how to retrieve, filter, join, aggregate, and analyze food delivery data.

## SQL Version

The queries are written mainly using **MySQL syntax**.
